# 1. ¿Qué diferencias encuentras entre las dos soluciones?

La principal diferencia es que usando el primer metodo debemos asignar el estilo por etiquetas lo cual puede suponer mucho trabajo, en cambio, con el segundo metodo podemos asignar a todas la etiquetas el mismo estilo usanod código escrito en la cabecera.

# 2. ¿Qué sucede si queremos aplicar el mismo estilo a diez páginas?

En este caso deberiamos usar un archivo externo el cual enlazamos al html usando la etiqueta <link rel="stylesheet" src="nombre_archivo.css">. Esto lo repetiriamos en las diez páginas web, lo cual es menos tardado que ir copiando y pegando código.

# 3. ¿Qué modalidad utilizarías en un proyecto real?

Yo en lo personal usaría siempre un archivo externo enlazado o tambien podría usar el código en el encabezado si el código html no fuera muy extenso.
