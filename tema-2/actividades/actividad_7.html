¿Qué es HTML5?

Introducción

HTML5 permite organizar el contenido de una página web mediante diferentes elementos estructurales y semánticos.

Entre ellos encontramos header, nav, main, section, article, aside y footer.

Organización de una página

Una página puede dividirse en una cabecera, una zona de navegación, un contenido principal, diferentes secciones, artículos y un pie de página.

Contenido complementario

Información adicional

El elemento aside permite colocar información relacionada con el contenido principal, pero que no forma parte directamente de él.
