📌 ¿Cómo subir y enlazar tus propios PDF a GitHub Pages?

Para que los documentos PDF se muestren directamente dentro de la aplicación, sigue estos pasos en tu repositorio:

  1. Crea una carpeta llamada pdf en la raíz de tu proyecto en GitHub.
  2. Guarda allí tus archivos con nombres simples, por ejemplo: actividad-tema1.pdf.
  3. Enlázalos en la etiqueta <iframe src="pdf/tu-archivo.pdf"> como ves en el visor de abajo.
